# Douyin UX Constitution

这份宪章是前端交互的默认约束。功能正确不等于体验完成；每个用户动作都要让人知道发生了什么、下一步能做什么，以及出错后如何恢复。

1. 用户操作必须立即获得反馈。
2. 低风险操作直接执行并优先采用乐观更新；失败时回滚。
3. 高风险或不可逆操作明确确认，能撤销时优先提供 Undo。
4. 网络失败不得丢失用户输入、草稿或已选择的媒体。
5. 页面导航必须可预测，Back、Close、Cancel、Exit、Home 语义不可混用。
6. 页面、Push、Bottom Sheet、Modal 的层级关系要能解释内容从哪里来。
7. 手势要符合直觉，滚动容器必须明确处理手势冲突。
8. 触控命中区至少 44px，图标本身不代表命中区大小。
9. 动画表达空间关系；支持 `prefers-reduced-motion`。
10. 首屏使用骨架或局部加载，避免无上下文的 Loading 文案。
11. 默认值替用户做合理决定，不重复询问已经知道的信息。
12. 页面返回后恢复用户上下文：滚动位置、播放位置、筛选和草稿。
13. 不能只用颜色表达状态，状态必须有图标、文字或 aria 语义。
14. 错误文案区分用户输入错误与系统暂时不可用，并提供重试路径。
15. 高频操作减少步骤，不用教程补偿糟糕的信息架构。

交互验收的最后一个问题始终是：用户是否几乎不需要猜测系统正在做什么？
